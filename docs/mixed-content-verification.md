# 중첩 Markdown 복합 콘텐츠 검증

2026-09-08. 실제 앱의 Markdown·KaTeX·차트·Mermaid 렌더러에 고정 응답과 제어 가능한 스트림을 전달해 검증했다. 서버 모델의 응답 품질은 이 검사의 대상이 아니다.

## 발견한 결함과 수정

구분자 없는 번호 수식을 복구하는 코드가 Markdown 컨테이너를 무시하고 문서 전체의 줄을 읽었다.

| 입력 | 수정 전 | 수정 후 |
|---|---|---|
| `> E=mc^2 \tag{1}` | 인용문이 사라지고 `>`가 수식에 포함됨 | 인용문 안에서 번호 수식 표시 |
| `- E=mc^2 \tag{1}` | 목록이 사라지고 `-`가 수식에 포함됨 | 목록 안에서 번호 수식 표시 |
| `1. E=mc^2 \tag{1}` | 원문 노출 | 번호 목록 안에서 수식 표시 |
| 제목·표 셀 안의 같은 수식 | Markdown 구분자와 충돌 | 제목·표 셀을 보존하면서 수식 표시 |

수정 전 실패하는 회귀 검사를 먼저 작성했다. 번호 수식의 탐색 범위를 Markdown AST가 제공하는 문단·제목·표 셀 본문으로 제한했다. 이어지는 줄의 인용 기호도 실제 인용 깊이만큼만 제외한다. 코드·주소 보호와 일반 문장을 수식으로 오인하지 않는 기존 검사는 유지한다.

## 추가한 검증 범위

- 일반 본문, 인용문, 번호 목록, 목록 안의 목록·인용문, 인용문 안의 목록에 같은 내용을 넣고 LF·CRLF 모두 검사한다.
- 표의 절댓값·근호·화학식, 링크 라벨의 분수, 다중 행 수식, 별행 적분, 번호 수식, 각주 수식을 함께 렌더링한다.
- 수식 7개의 정확한 원문, 표의 3열·2행, 차트 데이터 2열·2행, 실제 막대 2개와 Mermaid 노드 3개를 검사한다.
- 통화 `$100`, `$200`, `₩ 300`, 환경 변수 `$HOME`, 코드 안의 수식과 차트 펜스가 원문 그대로 남는지 검사한다.
- 각주 왕복 링크, 수식이 든 링크의 URL, 이미지 자리 표시와 자동 이미지 요청 0건을 검사한다.
- Chrome의 320·380·1000px 화면 및 인쇄 미디어에서 실제 렌더링, 문서 가로 넘침, 인쇄 표의 잘림을 검사한다. 같은 복합 입력을 배포 빌드에서도 검사한다.
- 수식·표 행·차트·Mermaid 펜스 중간에서 스트리밍을 나누고 미리보기와 최종 결과를 검사한다. 미완성 차트·흐름도는 자리 표시로 표시한다.
- `answer_reset` 후 재작성, 완료 이벤트 없는 연결 종료 후 재시도, 홈 이동 후 이전 요청의 늦은 조각·reset·done을 검사한다. 폐기한 답변이 새 화면이나 대화 이력에 들어가지 않아야 한다.
- UTF-8 및 JSON 이스케이프 중간에서 1·2·7·31·1024바이트 단위로 네트워크 데이터를 잘라도 이벤트와 최종 원문이 같아야 한다.

## 재현

수정 후 전체 프런트엔드 단위 검사 **182개**, 실제 Chrome UI 검사 **78개**, 배포 빌드 검사 **2개**가 모두 통과했다. 실패·건너뜀은 없었고 브라우저 콘솔 오류도 없었다. 수식 200개 표도 데스크톱·모바일·스트리밍·배포 경로에서 다시 통과했다. 320·380·1000px 화면을 저장하고 대표 화면의 조판과 배치를 육안으로 확인했다. 좁은 화면의 넓은 표와 수식은 내부 가로 스크롤로 읽는다.

입력은 [mixed-content-corpus.js](../frontend/test/mixed-content-corpus.js), 실제 화면의 공통 판정은 [mixed-content-checks.mjs](../frontend/test/ui/mixed-content-checks.mjs)에 있다.

`frontend` 디렉터리에서 실행한다. UI 검사는 Chrome과 로컬 서버를 열 수 있는 실행 환경이 필요하다.

```sh
npm test
npm run test:ui
npm run test:production
```

선택적으로 `MIXED_SCREENSHOT_DIR=/tmp npm run test:ui`를 실행하면 세 화면 폭에서 수식·차트·흐름도 부근의 스크린샷을 저장한다.

임의의 손상된 LaTeX까지 올바른 수학식으로 추측하는 것은 보장하지 않는다. 이 검증은 명시한 입력의 정상 조판과 주변 내용 보존, 실패·중단 시 상태 격리를 확인한다. 기존 수식 200개 표 전수 검사도 전체 UI·배포 검사에 포함된다.
