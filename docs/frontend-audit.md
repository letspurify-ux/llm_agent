## 재현하여 수정한 결함 12건

아래 결함은 production 코드 수정 전에 테스트 실패로 확인했다. 시간축의 눈금 문제는
소수 초 파싱을 고친 뒤 실제 차트를 렌더하여 추가로 확인했고, 눈금 수정 전 실패를 기록했다.
각 행의 테스트는 일회성 확인 코드가 아니라 저장소의 정식 테스트로 추가했다.

## 검증 결과

- 단위·실행 스크립트 테스트: **121개 통과**, 실패·건너뜀 0개.
- 실제 Chrome UI 테스트: **46개 통과**, 실패·건너뜀 0개.
- 실제 production 빌드 화면 테스트: **1개 통과**, 실패·건너뜀 0개.
- `npm run build` 성공. Vite의 기존 500 kB 초과 청크 경고는 남아 있다.
- `git diff --check`, 수정한 Bash 스크립트 구문 검사 통과.

기존 검증에는 수식·차트 파싱과 렌더, 오류 폴백, 링크·이미지 정책, 검색·조회 진행,
IME 전송, 좁은 화면·인쇄, 스크롤과 테스트 프로세스 정리가 포함된다.
추가로 최근 대화 6개/발화 1,500자 제한과 차트 값 보존, 같은 tick의 중복 제출 방지,
홈 복귀 뒤 옛 스트림이 새 대화의 상태를 변경하지 않는 동작을 확인했다.

production 테스트는 현재 소스를 새로 빌드하고 Vite preview의 실제 `dist/index.html`을 연다.
답변·수식·차트·흐름도·조회 표, 후속 질문의 이력, 홈 복귀와 콘솔 오류를 확인한다.
화면 캡처도 육안 확인했으며 테스트가 생성한 서버와 Chrome은 종료했다.

재실행:

```bash
cd frontend
npm run test:all
```

이 명령은 `npm test`, `npm run test:ui`, `npm run test:production`을 순서대로 실행한다.
`test:production`만 별도로 실행해도 현재 소스를 다시 빌드한다.

## 검증 환경과 범위의 한계

macOS, Node.js 25.9.0, Chrome 152.0.7977.65에서 실행했다. UI 테스트는 실제 frontend를
사용하되 `/api/chat` 응답을 고정하여 재현한다. 운영 DB·실제 LLM·운영 프록시를 통한
종단간 검증과 Windows 배치 파일 및 다른 브라우저의 실제 실행은 포함하지 않았다.
Windows 배치 파일은 정적 검토만 수행했다. 이 기록은 검토한 코드와 재현·검증한 경로의
결과이며, 모든 운영 환경에서 결함이 없음을 보증하는 문서는 아니다.

## 추가 정밀 검토 — 2026-09-06

이전 backend 검토의 미커밋 변경과 대소문자를 구분하는 차트 컬럼 선택 수정을 유지하고,
위 검토 범위의 frontend production 코드를 다시 검토했다. 이번 검토 시작 시의 전체 테스트는
단위·실행 스크립트 122개, Chrome UI 46개, production 1개로 모두 통과했다.

### 추가로 재현하고 수정한 결함 3건

| 결함 | 수정 전 재현 | 수정 | 정식 회귀 테스트 |
|---|---|---|---|
| 시간대 오프셋을 무시하는 차트 | `12:00 +00:00`과 `12:00 +09:00`이 같은 x로 읽혀 선 그래프가 표로만 표시됨. 같은 순간을 서로 다른 시간대로 적으면 반대로 서로 다른 x가 됨. `+24:00` 같은 잘못된 오프셋도 허용 | 명시된 오프셋을 검증하고 실제 순간으로 변환하여 정렬·중복 판단. 시간대 없는 날짜는 기존 지역 시간 해석을 유지. 표와 툴팁의 원래 시간대 표기는 보존 | `test/chart.test.js` 2개, `test/ui/ui.test.mjs` 1개 |
| 이스케이프된 닫는 대괄호를 수식 구분자로 사용 | `\[ x = 1 \\]`를 일반 텍스트 대신 KaTeX 오류로 표시하고 구분자가 사라짐 | 별행 수식도 여는·닫는 구분자의 이스케이프 여부를 확인 | `test/math.test.js`: 이스케이프된 대괄호 |
| 닫히지 않은 별행 수식을 닫혔다고 판단 | `$$` 하나가 빈 수식으로 사라짐. 문장 끝의 `$$` 또는 여는 `$$$`보다 짧은 닫는 `$$`가 있어도 본문을 수식 오류로 표시 | 별도의 닫는 줄, 달러 개수, 파서가 제외한 닫는 줄을 확인. 닫히지 않았으면 여는 달러 수를 포함한 원문 내용을 텍스트로 유지 | `test/math.test.js`: 별행 수식의 닫는 줄 |

production 수정 전 새 단위 회귀 테스트 4개와 기존 시간대 기대값을 바로잡은 테스트 1개가
실패했다. 시간대 차트는 실제 Chrome에서도 “유효한 두 시각이 차트 대신 표로만 나왔다”는
검증 실패로 확인했다. 수정 후 해당 테스트가 모두 통과했고, Chrome에서 서로 다른 두 점의
x 좌표를 확인했다.

추가로 날짜 테스트를 `Asia/Seoul`, `UTC`, `America/New_York` 환경에서 확인했다.
수식은 달러 개수·인용문·목록·빈 줄·LF/CRLF/CR의 108가지 조합에서 정상적인 별행 수식이
계속 그려짐을 확인했다. 서버와 공유하는 차트 계약 테스트 26개도 통과했다.

### 최종 검증

- 정식 회귀 테스트 **5개 추가**: 단위 4개, Chrome UI 1개. 기존 시간대 테스트의 잘못된 기대값도 수정했다.

- production 테스트가 현재 소스를 다시 빌드한 뒤 Vite preview에서 대화·수식·차트·흐름도·조회 표와 이력을 검증했다. 콘솔 오류는 없었고 캡처 화면도 확인했다.

이번 수정은 운영 DB나 실제 LLM 응답 경로를 변경하지 않는다. UI 검증은 앞서 기술한 것처럼
고정 API 응답과 실제 frontend 렌더링을 사용하며, Windows 및 다른 브라우저는 정적 검토 범위다.
