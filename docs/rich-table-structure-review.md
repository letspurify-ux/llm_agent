## 구조

[공통 구조 분석](../shared/rich-table-structure.mjs)은 수식·시각화가 소유한
파이프만 같은 길이의 문자로 가린다. 표의 열 수, 구분 행, 인용·목록·각주 경계는
기존 Markdown 파서가 판정한다. 투영한 AST에서는 구조와 좌표만 읽고, 값은
원문에서 다시 읽는다. 따라서 보호용 문자가 TeX·그림·조회값으로 전달되지 않는다.

표가 확정되면 각 행을 원문 그대로 분석한다. 문서 전체에서 임시로 인식한
인라인 코드나 링크가 새 행 경계를 가로지르면 그 소유권을 폐기한다. 참조 링크와
각주 정의는 행 분석에도 공유하며, 행 안 노드의 원문 위치를 문서 좌표로 옮긴다.
[수식 분석](../shared/math-spans.mjs)은 이 원문 AST와 구조 AST를 구분해서 받는다.
그 결과 정상 수식과 오류 수식 모두 같은 컨테이너 경계를 사용한다.

[직렬화 개행 처리](../shared/serialized-markdown.mjs)도 문서 구조와 내부 언어의
개행을 분리한다. 구조 발견에 쓰는 시각화 후보는 실행 대상이 아니다. 실제
Markdown 행 안에서 소유권을 확인한 범위만 보호·변환한다. 일반 코드 예시와
주소를 새 시각화로 실행하지 않는다.

이 분석을 서버의 조회 주입과 화면의 표 보호·수식 처리에서 공유한다. 종류별
명령 이름이나 특정 머리글 문자열을 추가해 고치는 방식은 사용하지 않았다.
기존 KaTeX·Mermaid의 문법 처리, 오류 원문 표시와 자원 요청 제한은 유지한다.

## 회귀 검사

[새 조합 검사](../frontend/test/rich-table-structure.test.js)는 노드 개수뿐 아니라
정확한 TeX, 차트 제목·조회 문자열·숫자, Mermaid 원문, 링크 주소, 이웃 셀과
오류 원문을 확인한다.

- 머리글 13종 × 컨테이너 5종 × 개행 5종 × 머리글 열 3종: 975개.
- 미완성 백틱·일반 코드·chart·Mermaid와 다음 행의 정상 콘텐츠: 405개.
- 가장자리 파이프 4종과 각주 컨테이너·실제 개행 3종: 156개.
- 자동 링크와 명시적 링크 주소·이웃 조회: 180개.
- 일반 코드, 산문, 잘못된 구분 행, 직렬화된 표를 담은 코드 예시: 56개.
- 미완성 수식 4종과 머리글·컨테이너·실제 개행: 780개.
- 머리글과 새 행을 받는 모든 스트림 접두사: 5,727개.

합계 2,552개 조합과 5,727개 접두사다. 별도 백엔드 문법 검사에서 조회 치환과
원문 좌표를 확인하고, GFM 최적화 확장을 독립 파서에 전달해도 기본 자동 링크
문법과 같음을 비교한다.

[실제 앱 검사](../frontend/test/review/rendering-browser.mjs)에는 새 머리글 13종을
`인용 → 목록 → 표 → 목록/인용 → 시각화 → 수식`으로 추가했다. 기존 사례와 합쳐
1,000px·320px에서 150회 검사한다. 실제 SVG·차트·MathML, 부모 컨테이너,
원문 링크, 글자 폭, 오른쪽 셀의 스크롤 도달, 페이지 넘침과 콘솔을 판정한다.

Mermaid 라벨의 가로 잘림은 글자 Range와 foreignObject의 폭을 대조한다.
MathML의 Range 높이는 선택 행 상자를 포함하므로 글리프 높이로 간주하지 않고,
수식 요소의 실제 크기와 내용을 별도로 확인한다. 캡처에서도 수정 전 머리글의
잘린 `label`과 수정 후 온전히 보이는 `label`을 직접 비교했다.

실행 명령:

```sh
npm --prefix backend test
npm --prefix frontend run test:regression
```

특정 화면만 확인하는 명령:

```sh
node frontend/test/review/rendering-browser.mjs --case=table-structure-unclosed-code
node frontend/test/review/rendering-browser.mjs --production
```

실제 DB·LLM 대신 고정 응답과 조회값을 사용한다. 라이브러리가 지원하지 않는
문법은 원문으로 확인할 수 있게 남긴다.

배포 검사는 위의 150개 실제 화면 조합을 포함한다. 수식·차트·Mermaid·원문 링크와

캡처에서 수식·조회 차트·그림과 오른쪽 셀을 직접 확인했다.

최종 실행에서 사용한 소스·테스트 파일의 SHA-256을 종료 후 대조해 변경이 없음을
확인했다. `git diff --check`도 통과했다. 테스트 조건이나 제한 시간은 완화하지 않았다.
